# Admit bounded ordinary v2 supporting review input

License: GPL-3.0-or-later.

## Context

Source owner: `octave-commons/muse`; initial planning artifact: `docs/agile/kanban/757e5c1d-3d68-4521-a4bd-65061b106697.md`. Parent: [complete-input epic](ca467d5e-db27-4cb2-8fe1-f24d389efa5d.md).

The original ordinary manifest admits only raw `basehead.diff`; treating a composite carrier as `full_diff` would change raw Git identity. Native PR28 findings `4267191720`, `4267191730` and `4267191736` expose missing independent producer binding, finite bounds and content admission in the support plan. Parent epic `ca467d5e-db27-4cb2-8fe1-f24d389efa5d` splits this boundary from component assessment and downstream native qualification.

## Outcome

The existing filesystem and public preparation boundaries accept an explicit ordinary `open-hax.review-input/v2` only when the original diff, summary and log are bounded, intact, independently bound to the actual trusted producer and authorized for model input; they return one immutable canonical component view for the existing review engine.

## Scope

Extend `law.review-invocation/input-source-valid?`, `shape.review-input`, `boundaries.node.fs/read-review-input` and `extern.review-invocation/prepare-review-invocation-context` with a shared pure v2 component descriptor/codec. A dedicated preparation export may be added only to expose that same owner implementation. This task owns admission and canonical immutable component/view identities; child `2c921c9e-08b3-4a18-b740-c19d2ffbf08b` owns tool delivery, role-specific assessment and invocation coverage. Shared interface is delivered here first, without a circular dependency.

The three roles and paths are exact and nonredirectable: raw-diff `basehead.diff`, summary `summary.json`, log `deterministic.log`. Keep the raw Git base/head/diff-base, full_diff byte/hash descriptor and preview semantics. Each component has its own byte count/digest. Proposed canonical layout is ordered lossless concatenation of the three decoded original texts, with trusted metadata recording each component's UTF-8 byte spans and separate UTF-16 text spans; no injected text marker becomes source text or a Git finding location. The shaped view has its own byte/digest identity. No physical combined file is required. Exact component order, span units and empty-component behavior are fixed in the reviewed law, never candidate-defined.

Trusted caller context independently establishes producer repository, reviewed head/base/diff-base, actual workflow path/ref/source SHA, run ID, actual producing attempt, actual producing job ID and uploaded artifact ID/native ZIP digest. A source manifest is not its own origin proof. Current reviewer attempt is separately recorded. An older producer attempt may be reused only through the existing successful prerequisite's actual output/artifact binding with unchanged head/workflow/native identity and explicit reuse provenance; never relabel it as the current producer attempt.

Proposed v2 resource profile: raw diff at most 4 MiB, summary at most 256 KiB, log at most 4 MiB, assembled view at most 9 MiB and at most 1,024 complete pages. Keep 8,192 UTF-16 units/128 lines per lossless page and preserve surrogate pairs. These are finite proposed limits for this ordinary-v2 profile, not changes to v1/native assessment bounds. They accommodate the measured 2,058,316-byte/268-page retained case with roughly threefold byte headroom, but impose no throughput guarantee. Stat and bounded reads enforce per-file limits before whole-file loading; aggregate/codec/page ceilings are checked with bounded counting before a complete page collection or model dispatch. Candidate manifests cannot raise these constants. Missing, malformed or oversize input refuses without truncation.

Model-admissible content policy is a trusted-producer obligation bound in the independently verified context: authorized public/explicitly authorized repository diff and deterministic review output only, captured by the reviewed producer from scoped evidence commands without signing credentials or customer/private-environment payloads in their execution environment/output. Preserve private setup/publication boundaries. Unknown producer/content authorization, sensitive classification or a known synthetic credential canary refuses before model dispatch. A manifest assertion alone cannot authorize content. This scope refuses unsuitable originals rather than silently rewriting them after hashing. It does not claim that a regex or structural schema recognizes every real secret or proves arbitrary prose safe.

## Non-goals

No general content-classification service, redaction system, artifact download service, arbitrary path support or second origin validator. Eta-mu owns native artifact observations; Muse owns their accepted context shape/admission. Existing P0 narrative card `9f35579b-e522-4445-a022-daa6f07ae3da` remains separately linked and does not supply origin admission. Tool/state/assessment changes belong to child `2c921c9e-08b3-4a18-b740-c19d2ffbf08b`.

No local fixture or green job substitutes for a genuine native review or normal source adoption.

## Risks

The producer's native artifact ZIP digest and extracted component digest are distinct. Job retry can honestly reuse an earlier producing attempt; strict provenance must not reject that supported case or manufacture freshness. Fixed 1,024-page refusal is necessary for many short lines. The initial bounds are an explicit proposal subject to planning review and measured final codec geometry; changing them later requires source review, never manifest overrides.
