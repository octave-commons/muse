## Outcome

A Muse host can opt into an authenticated Axxium MCP inbox stream and receive a wake hint for its exact configured actor and mailbox.

## Scope

Reuse the staged Axxium Streamable HTTP contract. Verify identity with the authenticated MCP tools before opening the stream. Carry a validated, local actor binding in each wake hint. The host adapter owns wake and session policy.

## Acceptance

- Verify the exact actor and mailbox and require advertised resource subscriptions.
- Open the GET stream before registering the inbox subscription. Pass only the exact MCP inbox notification to the host callback, without message payloads.
- Abort closes the stream and suppresses subsequent callbacks. Failures are visible to the caller. The receiver has no mailbox read, send, acknowledgment, polling, or replay loop.
- Prove the transport against a loopback fixture and reject a mismatched identity without opening the stream.

## Verification

Run focused ClojureScript tests against an isolated mock MCP endpoint and lint the added namespaces. Live staged host adapter testing is separate.
