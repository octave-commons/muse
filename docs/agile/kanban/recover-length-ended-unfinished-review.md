# Outcome

Provide a canonical Muse pure classifier and raw-JS boundary for a
healthy length-ended missing-submit invocation. Eligibility describes only a
new complete invocation; it never establishes accepted review or approval.

# Scope

Reuse canonical context, HOST, call, source, begin, stage-prefix and LAST law.
Require completed child exit 0, missing serialized submission and no submit call,
actual final step_finish reason length, stable caller-bound response/context
custody, exact canonical full-input geometry and returned page text, and complete
delivery/assessment before the first recorded stage. Reject unknown or failed
calls, malformed/nonunique/wrong-session traces, changed source/custody,
truncation, LAST violations and premature first stage.

Discovery anomaly: authentic Eta348 c5b run37709632725 records deterministic at
event36 before page reads39–111 and assessments42–114. It remains excluded by
the requested initial scope even though its input delivery eventually completed.
No native events are moved, projected, relabeled or treated as agreement.

# Non-goals

The length classifier does not change the stop requirement. The classifier
performs no model, provider or native invocation and grants no retry budget,
publication, adoption or approval. No tool, permission, model, reasoning,
credential, budget or quorum changes. Shared MAX2 and first-failure retention
remain separate Eta supervisor composition. A fresh review must reread/reassess,
re-establish all five stages, classify, submit, bind source and pass native App
publication/readback normally; no old credit transfers.
