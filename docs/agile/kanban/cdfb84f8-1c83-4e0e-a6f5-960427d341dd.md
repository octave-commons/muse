## Context

User-authorized scoped reviewer-workflow repair, planned before implementation.
Manual incoming Markdown input; no engine write ID, event, planning-review

## Outcome

The staged-diff index and deterministic publisher use the same exact repository
filename for Git C-quoted UTF-8 paths, including `.ημ/receipts.edn`.

## Scope

- Pure portable `.cljc` Git-path normalization at Muse's `+++` header boundary.
- Decode C-quoted UTF-8 octal bytes and supported ASCII/control/quote/backslash
  escapes before removing the destination prefix; preserve raw Unicode identity.
- Reject malformed/truncated quoting and invalid UTF-8 before a review session
  can approve incomplete or fabricated input.
- Retain added-head-line-only laws, canonical submission paths and defensive
  publisher validation; add meaningful red/green identity fixtures.

## Non-goals

No quotePath=false setting, dependencies, runtime migration, parallel ETA
parser, caller-pin update, review request, merge, deployment, receipt-finding
adjudication or claimed native inline publication. Do not modify the historical
receipt/event prefixes or the existing Muse #17 branch.

## Acceptance criteria

- [ ] Actual Git-emitted receipt fixture admits canonical path/added line.
- [ ] Raw Unicode and distinct normalization forms retain exact identity.
- [ ] ASCII, controls, backslash, quote and supplementary UTF-8 decode correctly.
- [ ] Malformed quoting, octal bytes and invalid UTF-8 fail closed.
- [ ] Quoted aliases never become index or submission paths.
- [ ] Rename destination, deletion, context and missing-file controls hold.
- [ ] Domain/publication tests, lint and existing host builds pass.
- [ ] Native source IDs, timestamps and proof hashes remain historical and explicit.

## Verification

Start with the already failed `.ημ/receipts.edn` index/admission assertions,
commit the red fixture, then rerun the same suite on the decoder. Exercise
canonical submission against the unchanged publisher and compile the shipped
review tools. Record actual results in append-only canonical receipts and the
verification note; parent qualifies hosted review and consumption separately.

## Risks

Octal values are UTF-8 bytes, not Unicode codepoints. Removing quotes alone
would preserve corrupt path identity. Malformed input must not silently drop a
file and permit a clean review. Never normalize case, Unicode or whitespace in
real filenames. Review approval does not prove receipt-anchor publication.
