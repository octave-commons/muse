# Audit: opencode agent model vs muse DSL (the defagent gap)

Muse's DSL (`eta-mu.dsl`) has `deftool`/`defhook`/`defplugin` but no
agent authoring form. Agents reach opencode two ways today:

1. Markdown copied from `.ημ/config/opencode/agents/` → `.opencode/agents/`
   (`emit-agents!`, src/clj/eta_mu/opencode/build.clj:158).
2. The `:agent` settings key (JSON) since fc58f52, which can also
   reconfigure built-ins.

Read the upstream agent implementation (`foresight/opencode`,
packages/opencode/src/agent + session) and list agent behaviors muse
cannot express: prompt `{file:}` resolution rules, per-agent model
fallback (subagent inherits invoker's model), hidden/system agents
(compaction/title/summary), task-permission glob semantics.

## Acceptance

- Gap list recorded on the card.
- A decision card: `defagent` macro vs settings-fragment-only authoring.
